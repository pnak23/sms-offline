ការដំឡើងកម្មវិធី KPSMS

ប្រសិនបើ Windows បង្ហាញសារ «Windows protected your PC»

  1. ចុចពីរដងលើឯកសារ KPSMS-Setup-1.0.0.exe។
  2. ប្រសិនបើ Windows បង្ហាញផ្ទាំង Windows protected your PC (SmartScreen) នោះមិនមែនមានន័យថាមានមេរោគទេ។ វាកើតឡើងព្រោះកម្មវិធីតម្លើងនេះមិនទាន់មានហត្ថលេខាឌីជីថលរបស់ក្រុមហ៊ុនបោះពុម្ព (ជាការសម្រេចចិត្តសម្រាប់ការចេញផ្សាយលើកដំបូង)។
  3. មុនពេលបន្ត សូមពិនិត្យថា ឈ្មោះឯកសារគឺ KPSMS-Setup-1.0.0.exe ហើយឯកសារនេះមកពីអ្នកដែលអ្នកស្គាល់ និងទុកចិត្ត។
  4. បើអ្នកចង់ពិនិត្យឱ្យប្រាកដថា ឯកសារមិនត្រូវបានកែប្រែ សូមបើក PowerShell ហើយវាយ៖
    Get-FileHash "ផ្លូវទៅកាន់ឯកសារ\KPSMS-Setup-1.0.0.exe" -Algorithm SHA256
    លេខដែលបង្ហាញត្រូវដូចនឹងលេខ SHA-256 ខាងក្រោម៖  
  5. បើត្រូវតាមលេខ សូមចុច More info រួចចុច Run anyway ដើម្បីបន្តការដំឡើង។
កម្មវិធីតម្លើងនេះមិនត្រូវការសិទ្ធិអ្នកគ្រប់គ្រង (administrator) ទេ។ បើ Windows សួររកពាក្យសម្ងាត់អ្នកគ្រប់គ្រង សូមឈប់ ហើយទាក់ទងអ្នកដែលផ្តល់ឯកសារនេះឱ្យអ្នក។
បើកម្មវិធីបង្ការមេរោគរបស់កុំព្យូទ័រនេះទប់ស្កាត់ ឬលុបឯកសារ សូមកុំបិទ ឬរំលងកម្មវិធីបង្ការមេរោគដោយខ្លួនឯងឡើយ។ សូមទាក់ទងអ្នកគ្រប់គ្រងកុំព្យូទ័រ ឬអ្នកដែលផ្តល់កម្មវិធីនេះ។
ព្រាង — មិនទាន់ត្រូវបានត្រួតពិនិត្យដោយអ្នកនិយាយភាសាខ្មែរកំណើតនៅឡើយ (សូមកុំចែកចាយមុនពេលត្រួតពិនិត្យ)។ លេខ SHA-256 ត្រូវបំពេញពីកំណត់ត្រានៃការចេញផ្សាយចុងក្រោយ។
