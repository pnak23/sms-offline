# Final school acceptance checklist

Written 2026-11-01 at the owner's request. **Development being finished is not the same as the school accepting the system.**
This file keeps every school-side item **PENDING** until the owner supplies verified information or a test on real hardware.
Nobody but the owner marks an item "Final school acceptance completed": the developer (me) never does, and no phase ends by flipping an item here.

**The program shows the same list.** Settings → About (អំពីប្រព័ន្ធ) lists every item below with its state, in the five states, and the administrator signs an item off there (a name and a date, kept in the database, audited, can be withdrawn). The shipped list is `release/acceptance.json`; it can only say whether the work is done and what is pending, and the build rejects a list that claims a sign-off. Screens that rest on information the school has not confirmed show a "not official yet" notice until the item is signed off. This file is the human-readable record; the sign-off in the program is the one that counts for the program, and section 4 below stays the owner's written record.

## The five states (they are different things and must stay different)
| State | Meaning |
|---|---|
| **Development completed** | The feature is built and tested on the development PC (the evidence is in the `PHASE*-PROGRESS.md` files). It says nothing about the school's real rules or real equipment. |
| **Configuration pending** | The program can be set up either way; the school has not yet chosen the value (a timetable, a currency). Nothing is invented in the meantime. |
| **Official information pending** | The real value or wording must come from an official source or an authorised person (grading rules, a report-card sample, the national header, a native speaker's approval). What is in the program now is a placeholder and must not be treated as official. |
| **Physical testing pending** | It has only been checked in files, PDFs or on the development PC. It must be tried on the real device (a USB stick, Windows 10, a clean PC, a printer). |
| **Final school acceptance completed** | The owner has checked the item for the school and signed it off below, with a name and a date. |
