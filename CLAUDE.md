## Facts that are not obvious from the code
- SQLite: `transaction_mode=IMMEDIATE` (deferred failed under concurrent writers); explicit AttributeConverters for dates (the driver's default is wrong);
  ×100 integer scores; Flyway runs on its own FK-OFF connection and asserts `pragma_foreign_key_check` after table rebuilds (`defer_foreign_keys` does NOT work).
- Start-up: extracted jar layout + `-XX:TieredStopAtLevel=1` helped (−52 %); AppCDS gave no gain.
- Electron IPC cannot clone Vue reactive objects → `toPlainData()` in `frontend/app/services/desktop.ts`. Chromium paints the window colour in PDF margins → white base colour.
- After a backend restart the port is reused (the page's CSP is bound to it). Single-instance lock is requested only after `userData` is set.
- Khmer: `Intl.Collator` has no `km` data (root collation sorts Khmer correctly); PDF text layer shows doubled vowel marks (extraction quirk, visible output is right).
- The real-shell tests catch bugs the browser/mocked tests cannot: after UI changes run `npm run e2e:app`, not only `npm run test -w frontend`.
  They do NOT rebuild: run `backend:build` + `extract-backend.mjs`, `generate -w frontend`, `build -w desktop` first. A page reload signs the user out (session is in memory), so UI tests must navigate through links, never `page.goto`.
- Jackson 3 answers 400 (not 422) when a request omits a primitive `boolean`; optional flags in request records are boxed `Boolean`.
- Java's launcher turns non-ASCII command-line arguments into `?` on Windows: pass Khmer-named paths in an environment variable (`SMS_DATA_DIR`), never as an argument.
- Migrations: V1–V5 (Phases 1–4), V6 (`acceptance_signoffs`) and V7 (`attendance_periods`, rebuilds both attendance tables) are complete and never edited again. V8 (sub-subjects, built 2026-11-05) is complete too. V9 (homework records, built 2026-11-05) is complete too. V10 (the weekly timetable, built 2026-11-06) is complete too. New schema = V11 (Phase 5 needed none: the backup history is `config/backup-history.json`, outside the database on purpose, because a restore replaces the database).
- **`release/release.json` is the only place the name and version are typed** (`docs/RELEASE.md`): the jar reads it from the classpath, the Nuxt title and Electron titles are built from it, `package.mjs` writes it into the installer; `node scripts/version.mjs check | sync | set` keeps `package.json` ×3, the lock file and `pom.xml` in step and `build-all` runs the check first. The schema number is a different number from the version. `package.mjs` needs `author` as an **object** (`{ name }`) or Windows shows Electron's own company ("GitHub, Inc.").

- **Attendance sessions** (`attendance_period`; "session" in the code already means one class's sheet for a day): a sheet snapshots its period's name and times, a period with sheets is switched off and never deleted, the last enabled one cannot be switched off, `UNIQUE (student_id, date, period_id)` stops a student twice in one session (across classes too), and **nothing is ever refused because of the clock**. A year starts with one period, ពេញមួយថ្ងៃ, with no times (`AttendancePeriodService.DEFAULT_NAME`). Attendance is counted **both ways** (built 2026-11-04, decisions D1–D8 approved as proposed): by SESSIONS (every sheet) and by DAYS (`attendance/DayStatus`: a date counts once per student; Present / Late / Partial / Absent / Leave; Partial is its own figure, never added to Present or Absent; a date with no record is not a day). The official method is the setting `attendance.officialBasis` (`DAY` until the school chooses; Settings → Attendance sessions); the dashboard and the report card follow it and say their unit (ថ្ងៃ / វគ្គ), the history, reports and Excel offer both. - Layout: `.page-container` has no width cap and is not centred; form pages add `is-form` (960 px), narrow ones `is-narrow` (720 px). The old 1100 px cap was why the app "stayed in the middle" when maximised.

## Tool quirks (Windows)
- A VS Code terminal may set `ELECTRON_RUN_AS_NODE=1`: Electron then starts as plain Node with no window. Clear it before `electron .` (test scripts do).
- npm may block dependency install scripts: if `node_modules/electron/dist/electron.exe` is missing, run `node node_modules/electron/install.js`.
- The project path may contain spaces: `scripts/run-mvn.mjs` already quotes it. JDK 21 comes from `JAVA_HOME` or `%USERPROFILE%\.jdks\corretto-21.0.6`.
- In the Bash tool an argument that starts with `//` (for example a text marker `"// ----"`) is turned into a Windows path: set `MSYS_NO_PATHCONV=1`.
- In the Bash tool, `\\` is collapsed before Python/sed see it; use the Edit/Write tools for anything with backslashes and run `node --check` afterwards. Several heredocs in one Bash call can fail as a whole: write files with the Write tool.
- `python` can be a Windows Store placeholder that hangs: use Node for scripts.
- **The VS Code Java extension (Eclipse compiler) writes into `backend/target/classes`.** A line javac accepts but Eclipse calls an error (seen: a bare lambda passed to `JdbcTemplate.query`, "ambiguous") becomes a stub class that throws `java.lang.Error: Unresolved compilation problem` at run time, and Maven then thinks the class is up to date. Symptom: a request that works alone answers **401 UNAUTHENTICATED** (the error dispatch to `/error` is not authenticated). Fix: write the call unambiguously (a `RowMapper` / `queryForObject`), delete `backend/target/classes` and `test-classes`, rebuild; check `getDiagnostics` for Java errors before a release build.
- A freshly built `.exe` is slow on its first run (antivirus scanning) — repeat timings before drawing conclusions.
