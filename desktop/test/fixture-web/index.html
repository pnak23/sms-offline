សាលាបឋមសិក្សា ភូមិថ្មី — បញ្ជីសិស្ស

សូមស្វាគមន៍មកកាន់ប្រព័ន្ធគ្រប់គ្រងសាលា។ ថ្ងៃទី ៣០ ខែ តុលា ឆ្នាំ ២០២៦។ សិស្សស្រីមានចំនួន ១២៣ នាក់ ហើយសិស្សប្រុសមានចំនួន ១៤៥ នាក់។
